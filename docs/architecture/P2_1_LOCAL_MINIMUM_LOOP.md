# P2.1 单用户本地最小闭环

## 范围

本阶段只实现：产品名称输入、身份闸门、最小澄清、任务状态流转、基础页面与自动化测试。

明确不实现：数据库、持久化、多用户、登录、真实模型、公开研究、知识库、训练、Word报告、任务队列和部署。

## 组件

- `apps/web`：Next.js本地页面，只调用应用API。
- `services/api`：FastAPI接口、确定性测试身份闸门、内存任务仓库。
- `agent/core/v1.1`：冻结系统提示词、工作流和任务边界运行摘要。
- `agent/skills/legal-report-review-and-verification`：锁定的Skill副本。
- `tests`与`evaluations/cases`：自动化测试和公开虚构回归用例。

## 状态流转

```text
待识别
├─ 名称不明确 ─→ 等待产品确认 ─┬─ 确认法律AI ─→ 研究中（P2.1阶段终点）
│                              └─ 确认非法律AI → 已终止
├─ 唯一法律AI ────────────────→ 研究中（P2.1阶段终点）
└─ 唯一非法律AI ──────────────→ 已终止
```

“研究中”沿用冻结数据字典的正式状态枚举；`phase_limit_reached=true`明确表示本阶段没有真正启动公开研究。

## 身份判断边界

P2.1没有接入公开搜索或真实模型。自动通过、歧义和越界路径只使用明确标注的虚构测试目录。任何未收录名称都会进入“等待产品确认”，不会依据名称相似度或模型常识自动判断。

用户明确填写确切产品全称后，只记录“用户确认”；运营主体、产品类型和关联生态仍留待后续公开核验。

## 数据与安全

- 任务只存在API进程内存，重启后清空。
- 不接收附件，不保存对话，不生成待入库包。
- 测试数据为虚构或泛称，不包含真实用户材料。
- 页面不持有模型、数据库或GitHub密钥。
