# P1实施基线

## 已确认决定

- 仓库：个人账号下的私有GitHub仓库。
- 外部服务：允许使用OpenAI、Supabase和Railway。
- 测试数据：仅限公开资料或不可逆脱敏数据。
- 当前范围：目录、基础说明、版本清单、忽略规则和基础检查。

## 未实施能力

前端、API、Agent、数据库、报告生成、模型调用、用户登录、远程服务和部署均未开始。目录占位不得作为功能完成的证据。

## P1验收

1. 目录和基础文件齐全；
2. `VERSION_MANIFEST.yaml`记录冻结版本；
3. 忽略规则覆盖密钥、用户材料和运行产物；
4. 基础检查能够阻止P1出现业务实现和明显敏感文件；
5. 私有远程仓库创建并完成首次推送；
6. 仓库可见性核验为private。
