# Legal AI Analysis Agent

面向法律AI产品公开信息研究、证据核验、分析报告生成、Word质检和知识反馈闭环的独立Agent项目。

## 当前阶段

当前为 **P1：工程骨架**。本仓库只包含目录、基础说明、版本清单、忽略规则和基础检查，不包含前端、后端、Agent、数据库或部署业务实现。

## 已冻结基线

- 法律AI分析Agent核心 V1.1
- 工作流与输入输出规范 V1.1
- 知识库与反馈闭环设计 V1.0
- 知识库数据字典与逻辑模型 V1.0
- 技术选型与部署方案 V1.0
- 实施准备与项目目录说明 V1.0

详细版本和兼容状态见 `VERSION_MANIFEST.yaml`，目录职责见 `PROJECT_STRUCTURE.md`。

## P1边界

允许：工程目录、说明文件、版本清单、配置名称示例、Git忽略规则和基础仓库检查。

禁止：业务代码、真实密钥、用户材料、报告、数据库、服务注册、模型调用和部署。

## 后续阶段

P1通过后才进入P2“单用户本地最小闭环”。P2首先实现产品名称身份闸门和任务状态机，不提前建立多用户生产系统。
